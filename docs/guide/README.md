# User guide and accessibility

The front view leads to solo/co-op strategies, an 83-tower simulator, and a lazily loaded defense scene. The scene supports an interactive 3D orbit, a switchable static 2D route schematic, arrow-key orbit, and 44×44 px controls. A screen-reader description explains the winding route, five towers, approximate range rings, enemy marker, and illustrative limits. If WebGL is unavailable, the 2D schematic is selected automatically and the unavailable 3D choice is disabled. With reduced motion enabled, the 3D scene renders a static frame without an animation loop; orbit controls remain usable, and a live system preference change switches the renderer appropriately. Focused checks cover the scene scheduler, touch-target sizes, the 2D path and tower markers, and descriptive alternative association. Article search downloads its title and full-source term index on demand; each article loads only when selected.

The readable article text currently uses the API's extract, while the complete imported source markup is available in an escaped expandable section. The API parse route returned a Cloudflare challenge to the current Node fetch context on 2026-09-26, so a complete formatted article renderer is still open work.

The implementation tracks the required per-surface completeness inventory in `docs/guide/completeness.md`. Any limitation must identify the exact contract, observed blocker, and shipped equivalent.
